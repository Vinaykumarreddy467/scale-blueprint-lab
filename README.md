# Scale Blueprint

Learn system design from zero to advanced by watching it run.

- **29 topics** in 5 levels, from "how a request travels" to event-driven architecture
- **19 live simulations**: load balancer, LRU cache, CDN, queues, replication, sharding, consistent hashing, CAP, rate limiter, circuit breaker, Bloom filter, geo index and more
- **10 case studies** with clickable diagrams and step-by-step request flows: URL shortener, Swiggy, Zomato, Uber, Netflix, WhatsApp, Hotstar, IRCTC Tatkal, UPI, Instagram
- Tools: 1 → 1B users scaling story, back-of-envelope calculator, 7-day study plan, quiz arena, 45-minute mock interview timer

Plain HTML, CSS and JavaScript. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Case-study diagrams are teaching designs built from public talks and common patterns, not any company's exact internal architecture.
